# Working in this repo as an agent

This repo is PUBLIC and served by GitHub Pages at https://rts-one.github.io/. Merging to `main`
publishes immediately, and everything committed here is world-readable forever.

- Never put customer names, prices, internal hostnames, internal URLs, file paths or secrets in
  this repo.
- Work on a branch and open a pull request against `main`. `main` is protected; a direct push is
  refused and every change needs the owner's approval.
- There are no tests. Open the changed page in a browser locally before opening the pull request.

The full contributor rules for the organization's private repos live in each private repo's own
AGENTS.md.
